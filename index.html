The browser build is the main way to try this project. This repository contains the source; the compiled WebAssembly package is generated locally and is not committed.

Checking for a built browser package…

Launch browser version

Build the static browser package from the repository root:

tools/web/package.sh
tools/web/serve.sh --web dist

Then open http://localhost:8642/ and select your GTA San Andreas folder.

The package includes the project's built-in executable-derived image data. Keep this repository and generated package private; publishing the package to a public static site would expose that data. See browser deployment notes.
